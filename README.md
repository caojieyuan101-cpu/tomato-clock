# 番茄钟 🍅

一个纯前端的番茄钟 + 时间记录 App。记录你在做什么、做了多久，并按 **日 / 周 / 月 / 年** 累计统计。

## 功能

- **计时**
  - 专注 / 短休息 / 长休息（默认 25 / 5 / 15 分钟，可在设置中修改，每 4 个番茄一次长休息）
  - **自由计时**：正计时，适合不按番茄节奏的事情，结束时点「完成」即记录
  - 开始、暂停、继续、放弃（不记录）、完成（提前结束并记录已用时间，≥1 分钟才记录）
  - 计时基于时间戳：切到后台、锁屏、刷新页面都不会丢失进度
  - 结束时提示音、震动、系统通知（需在设置中开启）
- **记录在做什么**：开始前在输入框写上事项，最近用过的事项会以标签形式显示，一点即可复用
- **统计**
  - 顶部卡片：今日 / 本周 / 本月 / 本年 累计时长，并显示与上一时段**同期**相比的涨跌（如「↑12% 较上周同期」）
  - 日 / 周 / 月 / 年 切换，可前后翻页查看历史，标题显示与上一时段的差值
  - **时间线**（日视图）：一天中每段时间在做什么，彩色色块一目了然
  - **按事项堆叠的柱状图**（周/月/年）：每天/每月的时间花在了哪些事情上；周/月视图带每日目标线；点击柱子可下钻
  - **洞察**：连续打卡天数与最长纪录、最佳一天、最长单次、活跃天数、目标达成天数、最专注时段
  - **按事项汇总**：时长、次数、占比
  - **日历热力图**：日/周视图显示最近 20 周，月视图是月历，年视图是 12 个月 × 31 天；颜色越深做得越多，最深 = 达成每日目标；点击某天直接查看当天
  - **习惯**：一天中哪个时段最专注、一周中哪天最努力（日均）
  - 每张图都可切换为「表格」查看具体数字
  - 事项颜色经过色盲友好校验，同一事项在所有图表中颜色一致
  - 周从周一开始；跨时段的记录按实际时间拆分到各时段
- **每日目标**：在设置中设定（默认 2 小时，0 为关闭），计时页显示今日进度条
- **记录**：按天分组的历史列表，可编辑、删除，也可「补录」忘记计时的时间
- **数据**：保存在本机浏览器（localStorage），可导出 JSON 备份 / 导出 CSV（Excel 可直接打开）/ 导入 JSON

## 使用

无需构建，任何静态服务器都可以：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

也可以部署到 GitHub Pages：仓库 Settings → Pages → 选择分支和根目录即可。

### 安装到手机

这是一个 PWA，用手机浏览器打开网址后：

- **iPhone（Safari）**：分享 → 添加到主屏幕
- **Android（Chrome）**：菜单 → 安装应用 / 添加到主屏幕

安装后可离线使用，像普通 App 一样从桌面打开。

> 提示：数据只存在当前设备的浏览器里，换设备或清理浏览器数据前请先在「设置」中导出备份。

## 快捷键

- `空格`：开始 / 暂停（计时页）
- 在事项输入框按 `回车`：直接开始

## 文件结构

```
index.html     页面结构
style.css      样式（自动适配深色模式）
app.js         计时、记录、统计逻辑
sw.js          Service Worker（离线缓存）
manifest.json  PWA 配置
icon.svg       图标
```
